# Vibe Marketing First — The Alternative Startup Playbook

> **Don't learn to code. Learn to sell first.**

This is the companion repo for the article: [How to Build an App from Scratch — The Marketing-First Approach](https://axelfreeman.com/blog/vibe-coding-guide.html)

## The Core Idea

Everyone tells you: "Learn to code, build MVP, launch." This is backwards.

**Code has zero value in 2026.** Everyone can vibe code. The scarce resource isn't coding ability — it's the ability to exchange words, images, and videos for human attention.

## Three Mistakes → Three Rules

| Mistake | Rule |
|---------|------|
| Building for a market with no buyers | Validate demand with words before code |
| Building 60% of what the market needs | Ship marketing first, ship product second |
| Expecting users in month 1 | Plan for 6 months of marketing grind |

## Start Here

1. Read the [full article](https://axelfreeman.com/blog/vibe-coding-guide.html)
2. Use the prompts below with your AI agent
3. Learn to trade words for attention
4. Then — and only then — learn to code

## AI Agent Prompts for Vibe Marketing

Copy-paste these into ChatGPT, Claude, or DeepSeek:

### Prompt 1: Validate Your Idea
```
I have an idea for [PRODUCT]. Before I write any code, help me validate if there's a market. Search for: similar products, online discussions about this problem, what people currently pay for solutions. Tell me if this market has buyers or if I'm building for nobody.
```

### Prompt 2: Write Your First Landing Page
```
Write a landing page for [PRODUCT]. Focus on the PROBLEM it solves, not the features. Keep it under 200 words. Make it feel like a conversation, not a sales pitch.
```

### Prompt 3: Generate Social Proof
```
Generate 5 tweets promoting [PRODUCT]. Each tweet should focus on a different angle: the problem, the solution, a customer story, a counter-intuitive insight, and a call to action.
```

### Prompt 4: Find Your First 10 Users
```
Help me find my first 10 users for [PRODUCT]. Where do my potential users hang out online? Which subreddits, Discord servers, Telegram channels, or Twitter communities should I join? What should my first post say?
```

## The Math

| Approach | Months to Revenue |
|----------|------------------|
| Code first, market later | 9+ months |
| Market first, code later | 3-6 months |
